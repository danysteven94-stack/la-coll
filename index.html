⚠ Baz done a poko konekte

Konekte yon baz done Vercel KV

Aplikasyon an ap eseye pale ak yon fonksyon sèvè (/api/entries) ki li/ekri nan yon baz done Redis (Upstash), disponib atravè Vercel Marketplace. Etap sa yo fèt yon sèl fwa, dirèkteman nan dashboard Vercel — pa gen kòd pou modifye.

  1. Ale sou vercel.com/dashboard, louvri pwojè "la-collection" ou a.
  2. Klike tab Storage → Marketplace Database Storage (oswa "Browse Marketplace") → chèche Upstash epi chwazi pwodwi Redis li a.
  3. Swiv etap yo pou kreye/konekte yon baz done Redis — chwazi pwojè "la-collection" pou konekte l. Vercel ap mete varyab yo (UPSTASH_REDIS_REST_URL, UPSTASH_REDIS_REST_TOKEN) otomatikman.
  4. Redeplwaye pwojè a (nan tab "Deployments", klike "..." sou dènye deplwaman an → "Redeploy").
  5. Rafrechi paj sa a.

🔍 Klike la a pou wè ki varyab Vercel jwenn (itil si erè a pèsiste).
